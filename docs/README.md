# Language server docs

Reference docs for the current state of the language server. Terms are defined in the [glossary](../GLOSSARY.md), and design decisions in the [ADRs](adr/).

- [Editor support](editors.md): setting up the language server in VS Code, Zed, Neovim, Emacs, Helix, JetBrains IDEs, and other editors.
- [Configuration](configuration.md): every setting that the language server reads from the client.
- [Internals](internals.md): the packages, threads, and the path of a notification or request, for contributors.
- [Testing](testing.md): testing conventions, fixtures, golden files, and the benchmark.
